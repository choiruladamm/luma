# Internationalization antarmuka ID/EN

Sudah di `master` (PR #191). Induk: [#184](https://github.com/choiruladamm/luma/issues/184).

## Kontrak produk

Luma mendukung Bahasa Indonesia dan English untuk antarmuka. Terjemahan, makna,
Bedahin, dan respons AI tetap Indonesia sebagai core produk.

- Default Indonesia, termasuk user existing. Pilihan eksplisit `id` / `en`; belum ada mode ikut sistem.
- Switch langsung tanpa restart; pilihan bertahan setelah relaunch dan ikut backup/restore.
- Copy aplikasi, format angka/tanggal/waktu relatif, plural, semantics, tooltip, toast dan notifikasi baru mengikuti pilihan.
- Judul, author, isi buku, metadata (termasuk fallback “Bab N”), input user, jawaban AI dan ChatStep tersimpan tetap dalam bahasa asal.
- Jejak langkah chat dari domain existing, termasuk attempt aktif, boleh tetap Indonesia; chrome/status UI di sekitarnya mengikuti locale.
- Bahasa UI tidak mengubah prompt, AI cache, parser, JSON protocol, format storage, ID, enum value atau filename backup.
- Switch mempertahankan route, reader position, draft/session chat, request AI dan antrean download. Tidak memicu request baru.
- Copy Indonesia mengikuti board existing; English santai, jelas dan natural. Nama app/model/provider tetap.
- OS-owned picker, share sheet dan permission prompt mengikuti mekanisme bahasa platform; switch Flutter tidak menjamin mengubahnya.

Pengaturan → tile Tampilan (sheet) menampilkan Bahasa antarmuka / Interface language, pilihan Bahasa Indonesia / English,
dan keterangan:

- ID: “Bahasa ini cuma buat tampilan. Terjemahan dan jawaban AI tetap Bahasa Indonesia.”
- EN: “This changes the interface language. Translations and AI responses stay in Indonesian.”

## Fondasi

Pakai `flutter_localizations` SDK, `intl` kompatibel Flutter pinned, dan `gen-l10n`
bawaan Flutter. ARB `app_id.arb` sebagai template, `app_en.arb` sebagai terjemahan,
output source generated di project dan mengikuti pola commit generated source repo.
Konfigurasi `l10n.yaml` dan `flutter.generate`; generator masuk Makefile existing
tanpa menghilangkan build_runner.

Simpan `app.locale` di tabel settings lewat SettingsRepository + stream provider
Riverpod manual. Missing/invalid fallback `id`; tanpa perubahan schema.
Backup memakai jalur DB existing. Restore wajib membuktikan stream/provider melihat
locale hasil restore, termasuk fallback backup lama tanpa key.

MaterialApp.router membaca locale/delegates/supportedLocales generated.
Preferensi awal diselesaikan sebelum frame konten agar saved English tidak berkedip Indonesia.
Read gagal fallback id; save gagal diberi feedback dan tidak diklaim persisted.
Router/ProviderScope identity tetap; locale bukan key subtree atau dependency AI.

Copy state dipetakan di UI extension/helper; domain/repository tetap pure.
Formatter menerima locale eksplisit, tanpa Intl.defaultLocale global.
Kalimat dinamis utuh di ARB, placeholder bertipe, plural English, metadata deskriptif.
Format wire/storage tetap. Tidak menerjemahkan konten tersimpan lewat regex atau AI.

## Implementasi

- `appLocaleProvider` membaca `SettingsRepository.watchLocale()`; default/fallback `id`.
  Root menahan frame konten sampai preferensi awal tersedia; read error memakai Indonesia.
  Pemilih menunggu write selesai; write error mempertahankan bahasa tersimpan dan memberi toast.
- Formatter di `ui/core/format.dart`, mapping buku di `ui/core/book_copy.dart`, mapping
  problem/status/legacy note chat di `chat_copy.dart`. Domain tetap bebas dependency localization.
- Config di `apps/mobile/l10n.yaml` (template `app_id.arb`, output `lib/l10n/`). `make l10n` menghasilkan source; `make gen` menjalankan l10n dan build_runner.
  `make check` menjalankan l10n, format, analyze, dan semua test. `test/l10n_test.dart`
  memeriksa parity key/placeholder, missing translation dan plural English.
- Test mencakup startup/fallback/router identity, gagal menyimpan bahasa, backup/restore DB nyata,
  chat aktif dengan draft/history Indonesia yang tetap, dan satu notifikasi English setelah
  download dimulai dalam Indonesia. Test layout memakai font asli pada 390×844 dan text scale 1.6,
  terang/gelap, ID/EN, ditambah kapsul/judul reader dan composer chat; link import Rak membungkus teks saat ruang sempit.
- `flutter_localizations` dan `intl` adalah dependency langsung. Hash lockfile di manifest replay evaluasi
  mengikuti aturan mutable lockfile; test membandingkan hash setelah normalisasi dua anotasi `pubspec.lock`.

## Belum diuji di device

Widget test dan `make check` tidak menggantikan bukti device. Masih terbuka:

- Luma Dev iOS: cold start English, switch, reader/chat aktif, backup/restore.
- Luma Dev Android: alur yang sama, unduhan foreground/background dan nama channel.
- Picker/share/permission OS: bahasa native mengikuti OS/app setting platform, bukan switch Flutter.

## Di luar scope

English AI, migrasi bahasa konten historis, perubahan ChatStep JSON, deteksi bahasa buku,
bahasa ketiga, RTL, cloud translation, schema/parser migration dan redesign.
